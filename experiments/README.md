# Experiments

One folder per experiment, named `<id>-<slug>` (for example `e1-macos-surface`).
The list of experiments and their order is in `../docs/spec.md` section 5.

Each folder has a README with:

- **Question:** the one thing it answers.
- **Setup:** machine, OS, GPUI version, clip, and how to run it.
- **Result:** the answer, with numbers.
- **Next:** what changes in the spec.

Experiment code may be rough; it is thrown away or promoted into the crate.
